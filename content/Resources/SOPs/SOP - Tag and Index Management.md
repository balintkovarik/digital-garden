
**Creating a tag**

1. Open any note
2. In the tags line, type `[[` and write the topic (e.g. `[[consumer psychology]]`)
3. Press Enter — Obsidian creates a blank note with that name
4. Move that blank note to your Tags folder (top-right dropdown → Move to folder)
5. Done. Reuse it by typing `[[consumer psychology]]` in any future note

**Rules for naming tags**

- Not too broad: `business` tells you nothing
- Not too narrow: `SleepAir Q2 Meta ads` you'll never reuse
- Sweet spot: `paid acquisition`, `brand positioning`, `sleep science`, `founder mindset`
- Ask yourself: _will I read something about this topic again in the next 6 months?_ If yes, it earns a tag

**How many per note**

- Aim for 2–3, hard cap at 5
- If you're struggling to pick, write the note more tightly — a note about too many things is the real problem

---

**Creating an index**

Trigger: a tag note has 10+ notes linking back to it (you can see this at the bottom of the tag note under "Linked mentions")

1. Open the tag note (e.g. `sleep science`)
2. Look at all the linked notes at the bottom
3. Add 2–4 subheadings that group them logically, e.g.:

```
## Mechanisms
## Behaviors & habits  
## Product implications
```

4. Under each subheading, paste `[[note title]]` links where they belong
5. That's your index — a hand-curated entry point into that cluster

**You don't need to be exhaustive.** Even linking 60% of the notes is enough. The index exists so you have a starting point, not a complete catalogue.

---

**The decision tree in one sentence**

New note → add 2–3 tags → if a tag note gets crowded → turn it into an index. Everything else is noise.
